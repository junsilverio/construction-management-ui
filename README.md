# Construction Management UI

A web-based Construction Management application built with Angular.

## Features

- **Dashboard** – Overview statistics: active projects, pending tasks, worker count, available equipment
- **Projects** – Create, view, edit, and delete construction projects with status tracking
- **Tasks** – View and filter tasks across all projects by status or project
- **Workers** – View all workers, their roles, and assigned projects
- **Equipment** – Track equipment inventory, status, and project assignments

## Getting Started

### Prerequisites

- Node.js 18+
- npm 9+

### Install dependencies

```bash
npm install
```

### Run development server

```bash
npm start
```

Navigate to `http://localhost:4200`.

### Build

```bash
npm run build
```

### Run tests

```bash
npm test
```
